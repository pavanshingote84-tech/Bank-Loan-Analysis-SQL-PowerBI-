# Bank Loan Analysis using SQL and Power BI

## Project Overview
This project focuses on analyzing bank loan data using SQL and Power BI to understand loan applications, funded amounts, and interest rate trends.

## Tools & Technologies
- SQL Server
- Microsoft Power BI
- CSV Dataset

## Project Files
- `Bank Loan Analysis Report.pbix` – Power BI Dashboard
- `SQLQuery.sql` – SQL Queries used for data analysis
- `financial_loan data.csv.csv` – Loan dataset

## Analysis Objectives
- Analyze total loan applications.
- Calculate total funded loan amount.
- Analyze average interest rates.
- Understand loan application trends.
- Present insights through an interactive Power BI dashboard.

## Dashboard
The Power BI report contains three pages:
- Bank Summary
- Bank Overview
- Bank Details

## Project Purpose
To practice SQL-based data analysis and create an interactive Power BI dashboard for understanding bank loan data.
